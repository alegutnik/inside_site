# INSIDE — сайт школы нумерологии

Замена Canva-сайта `inside3385.my.canva.site/inside` на обычную статику.
Ни сборки, ни зависимостей: открыл `index.html` — работает.

```
Сайт INSIDE/
├── index.html              ← вся страница
├── css/style.css           ← все стили (цвета и шрифт — в :root вверху файла)
├── js/main.js              ← анимации, счётчики, карусель, липкая кнопка, аналитика
├── assets/img/
│   ├── reviews/            ← 8 фото выпускниц
│   ├── ui/                 ← мокап телефона, короны, обложка видео
│   ├── bg/                 ← фоны тёмных секций
│   └── meta/               ← favicon, og-превью, иконка для домашнего экрана
├── img/                    ← исходники как есть, сайтом не используются
├── content.md              ← весь текст сайта, выгруженный из Canva
└── README.md
```

Шрифт — **League Spartan** (Google Fonts), тот же, что в оригинале.

## Как открыть локально

Просто двойной клик по `index.html`. Или, чтобы работало как на сервере:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

- Заголовок отзывов: «Результати **випускниць**», порядок карточек изменён.

## Интерактив

| Что | Где настраивается |
|---|---|
| **Тексты блоков программы** | массив `MODULES` в начале `js/main.js` — заголовок, результат, пункты, теги, плашка-итог |
| **Появление блоков при скролле** | атрибут `data-reveal` в HTML. Хочешь анимировать ещё что-то — просто допиши его элементу |
| **Счётчики** | `data-count="8"` у `.stat__num` |
| **Отзывы** | горизонтальная лента со снапом: свайп, стрелки и клавиши ←/→. Стрелки зациклены — с последней карточки прыгает на первую |
| **Липкая кнопка** | экраны ≤720px, появляется после первого экрана и прячется у футера, чтобы не дублировать тамошнюю кнопку |
| **Живой фон в hero** | `@keyframes blobA` / `blobB` в CSS, чистые градиенты — ничего не грузит |
| **Видео** | грузится только по клику, до этого висит обложка |

Всё уважает системную настройку «уменьшить движение»: при её включении анимации отключаются, цифры проставляются сразу.

## Картинки

Исходники лежат в `img/`, обработанные — в `assets/img/`. Сайт использует только
`assets/img/`; папка `img/` — архив оригиналов, её можно не трогать.

Пережато скриптом: **2.9 МБ → 900 КБ** (одна `Руденко Софія.png` весила 1.5 МБ).

## Пиксели и аналитика

Всё лежит в `<head>` файла `index.html`, закомментировано. Раскомментируй нужный блок и подставь свой ID:

- **Google Analytics 4** — `G-XXXXXXXXXX`
- **Meta (Facebook) Pixel** — числовой Pixel ID
- **TikTok Pixel** — sdkid

После подключения `js/main.js` сам начнёт слать события, ничего дописывать не нужно:

| Событие | Когда шлётся |
|---|---|
| `CTAClick` | клик по любой кнопке (в параметре `cta` — какая именно: `hero-primary`, `tariff-gold`, `deposit`, `support-1`…) |
| `SectionView` | посетитель долистал до тарифов / программы / отзывов / футера |
| `VideoPlay` | запустил видео |

Чтобы повесить метку на новую кнопку — добавь ей атрибут `data-cta="имя"`.

## Почему это быстрее Canva

Оригинал грузил ~14 JS-бандлов, WASM-модуль и собственный рантайм, который рисовал
страницу уже в браузере. Здесь — обычный HTML: браузер показывает текст сразу,
шрифт один, видео подгружается только по клику, картинки — лениво.

## Заметки по вёрстке

- Все цвета и шрифт — переменные в `:root` в начале `css/style.css`. Поменял там — поменялось везде.
- Иконки карточек «Що чекає всередині» — инлайновые SVG прямо в `index.html`, отдельных файлов не требуют.
  Это заглушки: если найдутся оригинальные иконки из Canva, их легко подставить.
- Адаптив: 3 колонки → 2 → 1. Карусель: 3 отзыва в ряд → 2 → 1.
- Если JS отключён, ничего не пропадёт: блоки прячутся только под классом `.js`,
  который ставится инлайновым скриптом в `<head>`.
